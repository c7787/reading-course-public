# 短视频脚本（30 秒 · 抖音 / 视频号 / 小红书）

> 用途：配合「扫码体验」海报与种子老师投放，做账号冷启动内容。
> 统一卖点：**拍张题图 → 30 秒生成可讲解的英语阅读课件**，老师零门槛、免注册、前 3 次免费。
> 拍摄建议：手机竖屏 9:16，前 3 秒必须出钩子，全程不露脸也可（录屏 + 配音 + 字幕）。
> 结尾统一引导：评论区扣「课件」/ 主页扫码 / 私信要链接。

---

## 脚本 1 · 抖音（强钩子 · 痛点前置）

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–3s | 老师深夜对着一堆试卷叹气，字幕「做阅读课件要多久？」 | 「英语老师最耗时间的，就是把阅读题做成能讲的课件。」 |
| 3–10s | 手机拍一张阅读题照片 → 打开网页拖入 → 进度条转 → 出课件 | 「现在，拍张图，30 秒，课件自己长出来。」 |
| 10–20s | 快速切：点句子出翻译+语法 / 点选项判对错 / 考点卡片 / 打印预览 | 「逐句精读、点选判对错、考点自动积累，还能直接打印。」 |
| 20–27s | 落地页特写 + 二维码，字幕「前 3 次免费」 | 「扫码免费用，前 3 次不要钱，课件可编辑可打印。」 |
| 27–30s | 手指点关注，字幕「评论区扣课件，发你链接」 | 「想要的老师，评论区扣个『课件』。」 |

---

## 脚本 2 · 视频号（信任向 · 同行圈）

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–4s | 一位老师口播（或字幕）：「我是教阅读的，今天分享个省时工具」 | 「同行分享一个我自己在用的阅读课件神器。」 |
| 4–14s | 录屏：上传 2 张不同题型 → 生成 A/B 两篇课件 | 「不管你是完形、阅读还是任务型，拍图就出双栏课件。」 |
| 14–24s | 展示教师讲解模式一键展开答案、打印教师版/学生版 | 「上课一键讲答案，下课打印学生版，全程不用加班。」 |
| 24–30s | 二维码 +「免费体验」徽标 | 「主页扫码免费体验，前 3 次免费，欢迎来试。」 |

---

## 脚本 3 · 小红书（审美向 · 图文感视频）

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–3s | 唯美封面：整齐的课件截图 + 标题「英语老师の偷懒神器」 | 「被夸课件好看的秘密，其实是它做的。」 |
| 3–13s | 慢节奏展示：左原文右题目、夜间模式、字号调节 | 「双栏排版、夜间模式、字号随意调，发给家长也体面。」 |
| 13–23s | 展示考点积累区 + 做题技巧卡，字幕「考点自动整理」 | 「单词、短语、考点、技巧，AI 顺手就帮你攒好了。」 |
| 23–30s | 二维码 + 收藏提示 | 「链接放主页了，先码住，备课时真用得上。」 |

---

## 拍摄 / 剪辑提醒
- **前 3 秒定生死**：抖音必须痛点/反差开头，别先介绍产品。
- **字幕必加**：刷视频大多静音，字幕决定完播。
- **二维码停留 ≥3 秒**且放大清晰，方便截图。
- **统一话题标签**：#英语老师 #教学资源 #课件 #阅读课 #教师日常
- **评论区运营**：有人扣「课件」就私信发体验链接，顺势拉群。

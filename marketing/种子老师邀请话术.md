# 种子老师邀请话术（找 10 位内测老师）

> 目标：用「免费 + 轻反馈」换 10 位真实老师试用，收集截图/吐槽，跑通转化漏斗。
> 投放渠道：微信私聊、教师群、朋友圈。先发「邀请」，再发「提醒」，最后「收反馈」。

---

## 一、首轮邀请（微信私聊 / 群发，1 对 1 更真诚）

> 适用：你认识的一线英语老师（初中/高中/机构均可）

```
XX 老师好 👋 我最近做了个小工具，专门给咱们英语老师省时间的——
拍一张阅读题照片，30 秒自动生成「能讲解」的互动课件（双栏排版、
逐句精读、点选判对错、考点自动积累，还能直接打印）。

想请你当第一批体验官 🧪 前 3 次免费，不用注册，手机扫码就能用。
你随手拍一两张平时的阅读题试试，用完跟我说句感受就行（哪怕一句"哪里别扭"也行）。

链接我发你，不方便试也没关系，纯当帮个忙～
```

**附**：体验二维码（见 `扫码体验海报.html` 部署后生成的图）或域名。

## 四、跟进提醒（2–3 天后，对没回的）

```
XX 老师，前两天发的课件工具麻烦抽空试一下哈～
就拍一张阅读题，30 秒出课件，看顺不顺手。
有啥槽点直接说，我这边正好改。链接还在吗？要我再发一遍不？
```

## 五、收反馈模板（试用后问）

```
太感谢了！帮忙回我三个小问题就行：
1. 生成快不快？课件顺手吗？
2. 哪个功能最有用 / 最鸡肋？
3. 如果收费，你愿意为"一学期不限次"付多少？（10/20/30+ 元？）
```

```

有想加的功能也随时说，我优先做。
```

## 运营小贴士
- **先私聊再群发**：熟人转化率高 3–5 倍。
- **降低门槛**：强调"拍一张就行""一句话反馈"，别让人有压力。
- **截图即素材**：老师发来的使用截图，打码后是最好的一组短视频素材。
- **拉群承接**：反馈聚集到企业微信群/微信群，二维码 upsell 自然闭环。

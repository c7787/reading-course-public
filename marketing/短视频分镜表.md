# 短视频分镜表（拍摄执行版）

> 把「短视频脚本.md」落到可拍：每条拆成镜号 + 时长 + 画面 + 字幕/配音 + 运镜。
> 通用前提：竖屏 9:16，1080×1920，全程加字幕（静音也能看懂），结尾二维码停留 ≥3 秒。
> 设备：手机 + 三脚架 / 稳定器即可；无出镜也可（录屏 + 配音）。

## 拍摄清单（开拍前核对）
- [ ] 手机横拿竖拍、分辨率 1080×1920、60fps
- [ ] 录屏用「屏幕录制」，关闭通知防弹窗
- [ ] 每条约 3 条备选 B-roll（翻试卷、敲键盘、学生作答）
- [ ] 字幕字号 ≥ 36，颜色白底描边，避免浅色背景看不清
- [ ] 结尾二维码用「扫码体验海报.html」导出的图，放大清晰
- [ ] 统一话题：#英语老师 #教学资源 #课件 #阅读课 #教师日常
- [ ] 发布后 1 小时内回复评论，有人扣「课件」就私信发体验链接
